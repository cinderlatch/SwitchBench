# Support

Use [GitHub issues](https://github.com/cinderlatch/SwitchBench/issues/new/choose) for reproducible bugs and feature requests. This is a community project; response times and compatibility fixes are not guaranteed.

Before reporting, read docs/TROUBLESHOOTING.md and check the latest release. Include the SwitchBench version, macOS version, Mac chip, selected tool, expected result, actual result and minimal steps. Describe formats and approximate sizes; a game title or ID is usually unnecessary.

Use More → Export Support Report if helpful, then **review and redact it yourself** before attaching. Automatic redaction is best-effort: reports can still include filenames, personal paths, account names, game identifiers, device names or server locations. Never attach prod.keys, title.keys, firmware, game files, certificates or unredacted logs. Prefer a small synthetic reproduction.

Game boot failures can be emulator-specific. A stored-data check cannot establish gameplay compatibility; compare only files you are authorized to use and avoid assuming every crash is a patching failure.

For security vulnerabilities, use SECURITY.md rather than a public issue.
