# AI development disclosure

SwitchBench was created with substantial assistance from **OpenAI Codex**, an AI coding agent, under the maintainer's direction. Codex generated and revised substantial portions of the native Swift interface, processing orchestration, container/compression code, tests, developer scripts, documentation and UX recommendations. It also helped diagnose failures and operate local QA walkthroughs. The original app icon is generated by the included AppKit drawing script, developed with this assistance.

The human maintainer supplied requirements, evaluated behavior, reported failures, selected the product direction, and confirmed gameplay/version results on their own Android emulator for earlier builds. The initial public repository and release preparation were also assisted by Codex.

## What this does and does not establish

- Automated tests, synthetic fixtures and agent-operated native checks are documented in QA-UAT.md. Those checks are useful evidence, not proof that all formats, games, devices or edge cases work.
- Independent novice-user research, a complete accessibility audit and an independent security audit have not been completed.
- AI assistance can introduce mistakes, insecure assumptions and misleading tests. Review code and verify outputs before relying on them. Maintainers remain responsible for accepting and releasing changes.
- Third-party code is credited and licensed separately. AI assistance does not replace upstream authorship or remove license obligations.
- This project is not an OpenAI product and is not endorsed by OpenAI. No claim is made about training data or undocumented model internals.

SwitchBench's runtime does not call Codex, ChatGPT or another AI service. It processes files locally; it does not need an OpenAI account or API key. See PRIVACY.md for the app's local data handling. Contributors should disclose material AI assistance in pull requests and take responsibility for reviewing and testing their changes.
