# SwitchBench 0.6.0 — independent usability sessions

This protocol is ready for human participants. Agent-operated walkthroughs do not count as independent human sessions.

Recruit two small iterative rounds of first-time users, including people with little technical experience and a keyboard/assistive-technology user. Use disposable fixtures and copies, never production originals for fault injection. Do not name the intended tool in a task instruction.

1. Make a new copy of this game with the newer update applied.
2. Keep this game, update and add-on together in one file. Explain how this differs from task one.
3. Find this game’s version, check its data, and explain what the check establishes.
4. Create an NSP copy from this XCI file.
5. Prepare this large file for a drive that cannot store a file over 4 GB, then restore the complete file from its parts.
6. Process this mixed set: one valid transformation, one healthy file requiring no change, and one damaged/wrong input. Find the saved result and recover only unfinished work.
7. Stop a long operation, identify what was saved, and retry safely.
8. Change one tool’s destination and confirm another tool’s saved results remain available.
9. Close and reopen the app, find a prior output in Recent Results, and check it.
10. Complete adding files, reviewing the plan, running the task and locating the output using only a keyboard.

Record independent completion, incorrect tool choices, output-location mistakes, recovery attempts, requests for help, reliance on technical logs and interpretation of success. Use time diagnostically; do not reward fast mistakes. In a seven-person iteration, a proposed target is six independently completing each primary task, with everyone understanding that originals stay unchanged and finding the saved output. Investigate each failure. A small sample is directional, not proof of universal usability.

Test light/dark appearance, Increase Contrast, Reduce Transparency, smaller laptop windows and VoiceOver with the participant’s normal configuration. Record contrast measurements and assistive-technology failures separately from opinions about appearance. Notification opt-in is optional and should never appear during ordinary first use.
