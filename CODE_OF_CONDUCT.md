# Code of conduct

Help make this project welcoming and useful. Be respectful, patient and constructive. Focus criticism on behavior and code. Respect different experience levels, backgrounds and accessibility needs. Assume good intent while taking reported harm seriously.

Harassment, discrimination, threats, doxxing, sexualized conduct, personal attacks, spam and deliberate distribution of private data or prohibited content are not acceptable. Do not pressure contributors to provide unpaid support or share private keys/game content.

This policy applies to repository issues, pull requests and other project-managed spaces. Maintainers may edit/remove content, close or lock discussions, restrict participation or block accounts to protect the community. They should explain decisions where doing so does not expose private information.

Report concerns through a private GitHub channel to the maintainer when available. If no private channel is available, ask for one without identifying the affected person publicly; use GitHub's reporting tools for urgent platform abuse. Maintainers should keep reports confidential as far as reasonably possible and avoid conflicts of interest.

This is a project-specific policy, not a claim to adopt a third-party conduct template verbatim.
