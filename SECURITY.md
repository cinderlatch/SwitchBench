# Security policy

## Supported versions

Security fixes are targeted at the latest release and main branch. Older releases do not have guaranteed backports. SwitchBench processes complex untrusted file formats through native code; it is not sandboxed or independently security-audited. Treat unfamiliar files cautiously.

## Report privately

Use [GitHub's private vulnerability reporting](https://github.com/cinderlatch/SwitchBench/security/advisories/new) when enabled. If that page is unavailable, open an issue asking only for a private contact channel; **do not post vulnerability details or sensitive data publicly**. No security email address is currently designated.

Include the affected version, platform, impact, minimal reproduction and synthetic sample if possible. Never include production/title keys, commercial game content, certificates or private personal logs. Do not exploit other users' systems, test destructive cases against their data or publish details before maintainers can assess them.

There is no guaranteed response or fix deadline and no paid bug bounty. The project will acknowledge, investigate and coordinate disclosure as maintainer capacity allows.
